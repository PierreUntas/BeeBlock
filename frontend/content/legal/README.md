# Légal — copies de travail pour le bundle frontend

Ces fichiers sont des **copies** des sources canoniques situées dans `/docs/legal/`.
Ils existent ici uniquement pour que Next.js puisse les inclure dans le build Vercel.

**Source de vérité** : `/docs/legal/` à la racine du repo.

**Quand mettre à jour** : à chaque modification d'un document juridique (validation
juriste, changement de statut éditeur, mise à jour CGV, etc.), copier la nouvelle
version depuis `/docs/legal/` vers ce dossier puis commit.
